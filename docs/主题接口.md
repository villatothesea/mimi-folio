# 米素主题接口

## 参考源码库的主题机制（只看交互，不抄代码）

| 库 | 机制 | 借鉴点 |
| --- | --- | --- |
| Tolaria（AGPL，只看交互） | shadcn 风格 CSS 变量（`--accent-*`、`--foreground`）+ `themeMode` 明暗 + `theme.json`（编辑器排版：字号/行高/各级标题）+ AccentColorPicker（用户选强调色） | 明暗二态 + 强调色可选 + 排版独立成配置 |
| MarkText | `themes/*.css` 每主题一份 CSS 变量文件（`--editor-*`），切换 = 换挂的样式表 | "一主题一文件"，变量集就是接口 |
| muya | 全部外观吃 `--editor-*` / `--mu-*` / `--float-*` 等变量，自带默认值 | 我们已在 `src/theme/muya.css` 全量映射到 `--folio-*` |

三家同一结论：**主题 = 一组 CSS 自定义属性的值集**。

## 米素的主题接口（现状即接口）

```
tokens.css        亮色基准值（:root）—— 接口的"定义处"，变量清单 = 接口
tokens-dark.css   暗色覆写（:root[data-theme='dark']）
muya.css          --mu-*/--editor-* → --folio-* 的映射（主题无关，不许再动）
组件 / app.css     只消费 var(--folio-*)，换主题零改动
```

**加一个主题 = 加一个文件**：新建 `src/theme/tokens-<名字>.css`，选择器 `:root[data-theme='<名字>']`，覆写想变的 `--folio-*`（不必全量）；`main.ts` import 它；`applyTheme` 的类型联合加这个名字。切换挂 `document.documentElement.dataset.theme`，持久化 localStorage。

**变量分组**（tokens.css 的注释即契约）：底/面板/前景/边框/悬停/选区/主强调（`--folio-primary`）/阴影/字号/行高/间距/圆角/控件高（`--folio-control-h`）/正文列宽（`--folio-measure`）/标签色板（`--folio-tag-0..7`）。

## 已落地的两个可调项

- **明暗**：底栏「主题」按钮（单元 12），dark 只覆写色值 token。
- **标签色**：`--folio-tag-0..7` 八色板（亮/暗各一套），`src/ui/tagColors.ts` 按名散列取色、点击芯片可改，选择存 localStorage（视图偏好，不进 md——内容分类仍只有目录 + frontmatter）。

## 以后可加（排队，不急）

- 强调色选择（Tolaria AccentColorPicker 交互）：覆写 `--folio-primary` 一个变量即可，UI 上放底栏。
- 排版主题（Tolaria theme.json 思路）：把 `--folio-measure`、字号 token 暴露成设置项。
- 用户自建主题文件：合入米米后由 daemon 端资产层放 `themes/*.css`，页面按列表挂载——**不破 "只改 token 值" 纪律**。
