# Tolaria UI 复现研究（只看交互，不抄代码）

> 对象：`Assets/tolaria-main`（AGPL-3.0，Tauri 桌面应用，BlockNote 编辑器）。
> 协议红线：**交互与信息架构可借鉴；组件代码、CSS、图标、文案一律不取**（AGENTS.md 硬规则 1）。
> 本文只描述"界面上有什么、点了会怎样"，作为米素后续单元的需求参考。

## 它是什么

桌面端 markdown 知识库管理器，定位万人笔记规模（作者自述 10000+ 篇）。四区布局：

```
┌─────────┬──────────────┬───────────────────────┐
│ 侧栏     │ 文档清单       │ 编辑器                  │
│ 导航/收藏 │ 筛选+搜索+列表  │ 面包屑+属性+标题+正文     │
│ 类型/文件夹│ (+关系分组视图) │ +右侧目录(TOC)面板       │
├─────────┴──────────────┴───────────────────────┤
│ 底栏：计数·git 同步·vault 切换·缩放·主题·设置          │
└────────────────────────────────────────────────┘
```

## 元素清单（按区域，交互级）

### 侧栏 Sidebar
- 顶部导航：←/→（浏览历史回退/前进，同 wikilink 点击历史）、折叠按钮
- 收藏区：星标的笔记/文件夹置顶，可拖动排序
- 类型区（笔记类型，近似"分区"）：彩色圆点 + 名称 + 计数；可重排、改色、设模板、隐藏、重命名、删除；`+` 即时新建该类型笔记
- 文件夹树：层级目录，拖放笔记入文件夹移动、行内重命名、右键删除
- 保存的视图（saved views）：自定义筛选组合，可编辑/排序/删除
- 全部可折叠分区，宽度可拖拽调整

### 文档清单 NoteList（独立一列，宽度可调）
- 头部：当前视图名 + 计数，可展开/收起
- 筛选 pills：全部打开 / 收件箱 / 变更(git) / 动态(pulse) / 回收站……各带计数
- 搜索：全文搜索，键盘导航（上下选择、回车打开），多字节安全高亮
- 列表项：图标 + 标题 + **副标题元数据行**（状态/日期/路径）+ 彩色状态点 + 收藏星标 + git 修改徽标 + 归档横幅样式；置顶卡（Pinned）
- **关系分组视图**：选中一篇时，清单按"链接到这篇 / 这篇链到"分组展示（列表里直接看见双链邻居）
- 多选（Shift/Ctrl）+ 批量操作条（归档/整理/删除）
- 右键菜单：重命名文件名、导出 PDF、开新窗口、收藏、在系统文件管理器显示、复制路径、复制 Git URL、丢弃修改
- 列表属性浮层：可配置每列显示什么、排序

### 编辑器区
- 标签页：多文档多开（tabs，可关、可替换）
- 面包屑条：文件夹路径逐级可点
- 属性区（frontmatter 可视化编辑）：图标选择、状态下拉（StatusDropdown）、`+添加属性` 行内表单——就是我们 Obsidian 式属性面板的进阶形态
- 标题：H1 即文件名（改标题=改文件名），有专门的交互处理（粘贴目标、自动改名）
- BlockNote 块编辑器（悬浮格式工具条、callout 块、表格等）
- **文档目录 TOC 面板**：右侧竖条；H1–H6 缩进树，每级一个标题图标；点击滚动定位并高亮当前所在节；可关闭；标题树由 Web Worker 离主线程计算（万篇性能）

### 底栏 StatusBar
- 左：笔记总数、git 修改数（点击 → 清单切到"变更"筛选）
- 中：当前 vault 路径 + vault 切换菜单（多库、设默认库、克隆、新建空库）
- git 同步状态：拉取/推送按钮、冲突数（点击开冲突解决器）、离线标记、最近同步时间
- 右：缩放（点击重置）、明暗主题切换、设置、反馈、文档、构建号/检查更新、MCP 状态、AI 徽章
- （Linux 无系统标题栏时自绘顶栏 LinuxTitlebar——桌面专属）

## 复现评估（米素栈：muya + folio token + host）

### 绿：现有能力直接铺 UI，推荐做
| 元素 | 米素落点 | 量 |
| --- | --- | --- |
| 文档目录 TOC | `muya.getTOC()` 现成 + 点击 `setCursorByOffset` 滚动定位；右侧面板 + 当前节高亮（监听光标所在标题） | 小 |
| 底栏 | 字数（muya `wordCount`）、笔记数（`host.list`）、保存状态（挪现有 save-state）、明暗切换（覆写 `--folio-*`，正好验证 token 纪律） | 小 |
| 清单升级 | 现侧栏列表加：筛选 pills（全部/速记/长文/回收…带计数）、搜索框（list 全量内存过滤）、副标题行（tags/日期） | 中 |
| 收藏 | frontmatter `favorite: true` + 侧栏置顶组（仍是 md 里的分类，不是第三种库） | 小 |
| 面包屑 | 现有 current-path 改逐级可点 | 小 |
| 属性进阶 | 现有属性面板加 `+添加属性`（任意键值）与状态下拉（值枚举存 frontmatter） | 中 |

### 黄：能做但要排队
- **标签页多开**：单文档状态 → tabs[]，muya 实例切换/缓存策略（现在每次重建；万篇规模再议实例池）。约一个单元
- **跨文档全文搜索**：拉全量 md 内存搜（千篇级可行）；Tolaria 的规模优化（worker）暂不需要
- **关系分组清单**：我们已有 `index()` 出链/反链——把反链面板挪进清单列做分组即可，但计划说"不是 vault 产品"，建议保持现在的底部面板形态
- 文件夹树：**计划明确不做**（单元 5 纪律："目录就是分组"，不做文件夹树）；Tolaria 有是它桌面定位
- 保存的视图：暂不排（有标签筛选已够最低线）

### 红：不抄也不做（Tolaria 的桌面/团队定位，与米素无关）
- git 同步/冲突/离线、多 vault 管理、新窗口、导出 PDF、MCP/AI 面块、系统标题栏——这些合入米米后归 daemon/主窗，浏览器层不碰

## 结论

**能复现，且大头是"铺 UI"不是"造引擎"**：TOC、底栏、清单筛选/搜索/副标题、收藏、面包屑都在米素现有 API（`getTOC` / `wordCount` / `host.list` / `setCursorByOffset`）与 token 体系内，合计约 2–3 个单元。tabs 多开另算一个。git/AI/多库属于 Tolaria 桌面定位，既不该抄也轮不到米素做。

建议排期（若要做）：**单元 12 = TOC 面板 + 底栏**（都是小活，合一条）；**单元 13 = 清单列升级（pills/搜索/副标题/收藏）**；tabs 视愿再排。待用户点头再进计划表。
