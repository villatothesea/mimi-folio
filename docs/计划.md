# 米素 · 施工计划

产品名 **米素**；仓名 **folio**。米米的**记忆底座**（人看、米米整理），不是「先当编辑器再补功能」。独立做完，再合进米米。合入口预留在 `src/host/`。

选型依据：`Mimi/docs/调研/md页选型.md`。

`memory.db` 仍是进提示的 2KB 档案。人读的记忆是这座 vault 里的 md。两层，不是两种库。

---

## 三件不同的事（不要混成一个）

| 要干什么 | 用什么 | 不够用的替代 |
|---|---|---|
| 这篇**连到**那篇（人物、项目、一篇长文） | `[[wikilink]]` + 反链 | 标签。标签没有「那一页」 |
| 这条**属于**哪一类（可多选，速记刚需） | frontmatter `tags:` | 单靠 wikilink。每类都造一页、每条速记都得链过去，摩擦太大 |
| 文件**放在**哪（互斥的一组） | 目录：`notes/` `memos/` 以及其下文件夹 | 再做一套「分组」字段。目录就是分组 |

所以：**wikilink 不够当分类。** 双链是图，标签是多对多，目录是互斥位置。三件都要，但只这三件——不要再加 Tolaria 那种 type / Notion 属性。

**库外的 md** 不是第四种分类：真源仍在项目目录，vault 里只放符号链接（单元 10）。不要拷进 `notes/` 变成第二份。

速记（memos 那种时间线 + 标签）是同一座 vault 的一种**看法**，目录 `memos/`，不是下一场、不是嵌 Go 版 memos。

## 合入（先钉，再写码）

米米这边不变：主窗 GPUI；米素是随安装包的本地 Web；浏览器只是显示器。Daemon 不依赖本仓；本仓不依赖 gpui。API + 索引跟 daemon **常驻**；浏览器开不开是用户选项。

```
独立时                         合入后
浏览器 → StandaloneHost  → 磁盘     浏览器 → MimiHost → daemon HTTP → 资产层 vault
         （本仓小服务）                    静态 dist/ 由 daemon 或 mimi://folio 端出
         read 跟随 links/ 符号链接          链进 vault 由米米问你再调 linkOutside
```

**契约**（`src/host/types.ts` 现在只是建仓时的桩：`read` / `write` / `list` / `saveImage` / `index?`。下面这些是计划，**对应单元开工再改类型**，合入后方法名仍不许改）：

| 方法 | 现在 | 合入 |
|---|---|---|
| `read(path)` | 读 vault 下 md | `GET /folio/v1/doc?path=` |
| `write(path, markdown)` | 写回同一文件 | `PUT /folio/v1/doc` |
| `list(opts?)` | 按目录/标签/kind 列 | 同路径，daemon 扫资产层 |
| `saveImage(bytes, hint)` | 图 → `attachments/` | daemon 落盘，回相对路径 |
| `saveFile?(bytes, hint)` | 音视频等同附件目录 | 同上 |
| `index(path)` | 出链 / 反链 | daemon + iwe 算法，不跑 LSP |
| `linkOutside({ absSource, destRel })` | 单元 10 开工再加类型 | 你同意后，vault 里建指向库外 md 的符号链接（不拷贝） |

探测：`?host=mimi` 或 `window.__MIMI_FOLIO__` → `MimiHost`。合入只加适配器 + 端静态文件，**不改编辑器**。

合入时米米要做的（本仓不写）：

1. 安装包带上 `dist/`（程序层）。
2. daemon 上述 HTTP。vault 在资产层，与 `memory.db` 分开。
3. 主窗按钮 / 会话里打开指定 path；服务常驻，浏览器关了服务还在。
4. 计划门：write 是否 L2，由米米定。

## 单元（一提交一条）

| # | 做什么 | 算完 |
|---|---|---|
| 0 | 仓骨架 + Host + vault 目录约定（`notes/` `memos/` `attachments/`）+ Standalone 读写 | `pnpm dev` 起得来；能读到示例 md |
| 1 | 挂上 Muya，打开/保存一篇长文 | 预览即编辑；刷新内容还在 |
| 2 | `/` 菜单；关 PlantUML、关开放 HTML 斜杠；数学 + Mermaid 开 | 能插标题/表/公式/mermaid；插不了 plantuml |
| 3 | `--mu-*` 从 `--folio-*` 映射；出厂灰阶 | 组件无写死色 |
| 4 | 本机多媒体：图走 `saveImage`；音/视频走 `saveFile`，落盘 `<video>`/`<audio>`（Muya html-block 已能预览） | 盘上有文件，md 里是相对路径，页里能播 |
| 5 | 分组：按目录列出（`notes/` / `memos/` / 子文件夹），点开一篇 | 目录即分组；不要另做分组表 |
| 6 | 标签：frontmatter `tags:`；列表能按标签筛 | 一条可多标签；不靠 `[[标签页]]` |
| 7 | `[[wikilink]]`：Foam 规则 + SilverBullet 芯片；`index()` 出链/反链 | 点击跳转；反链能看见谁链过来 |
| 8 | 速记看法：`memos/` 时间线 + 标签，新建短 md | 不是嵌 memos；仍是 `.md` |
| 9 | 链接播视频：粘贴 YouTube / B 站等白名单 URL → 页内播放；md 里只存链接 | 任意 iframe 不进盘；DOMPurify 本就会剥 iframe |
| 10 | **外链进 vault**：`linkOutside`；`vault/links/` 符号链接指向库外 md；read/write 写回原文件；list 标 `linked` | 项目里一份 md，同意后米素能打开；盘上无第二份正文；失败不落成拷贝 |
| 11 | 查找替换：页内搜索条（`muya.search/find/replace`），回车下一个、Shift+回车上一个、可替换单处/全部 | 能搜能跳能换；Esc 关闭 |
| 合 | 米米仓 `MimiHost` + 端 `dist/` | 独立模式仍能跑 |


一次只领一单元。顺序 **0 → … → 11 → 合**。这是记忆底座的最低线，不是「编辑器凑合能合」。

彩色主题仍不是现在的活：出厂灰阶；换色只覆写 `--folio-*`。

## 视觉（纪律，不是可选）

组件、侧栏、图标、Muya 宿主层**不许写 hex / rgb / 字号像素**。只认 `var(--folio-*)`。色值只出现在 `src/theme/tokens.css`。

出厂：白底、近黑字、灰线。Cadmium / 米米色板以后是 token 文件，不要贴进组件。
