# 米素 · 施工计划

产品名 **米素**；仓名 **folio**。本地笔记库（人写、人看；米米也可以整理），不是「只许展示不许写」。也不做成 Tolaria 那种多库/文件夹树/git 桌面套件。独立做完，再合进米米。合入口预留在 `src/host/`。

选型依据：`Mimi/docs/调研/md页选型.md`。

`memory.db` 仍是进提示的 2KB 档案。人写的笔记是这座 vault 里的 md。两层，不是两种库。人自己写不经过米米，也完全合法。

---

## 三件不同的事（不要混成一个）

| 要干什么 | 用什么 | 不够用的替代 |
|---|---|---|
| 这篇**连到**那篇（人物、项目、一篇长文） | `[[wikilink]]` + 反链 | 标签。标签没有「那一页」 |
| 这条**属于**哪一类（可多选，速记刚需） | frontmatter `tags:` | 单靠 wikilink。每类都造一页、每条速记都得链过去，摩擦太大 |
| 文件**放在**哪（互斥的一组） | 目录：`notes/` `memos/` 以及其下文件夹 | 再做一套「分组」字段。目录就是分组 |

所以：**wikilink 不够当分类。** 双链是图，标签是多对多，目录是互斥位置。三件都要，但只这三件——不要再加 Tolaria 那种 type / Notion 属性。

**库外的 md** 不是第四种分类：真源仍在项目目录，vault 里只放符号链接（单元 10）。不要拷进 `notes/` 变成第二份。

速记（memos 那种时间线 + 标签）是同一座 vault 的一种**看法**，目录 `memos/`，不是下一场、不是嵌 Go 版 memos。

## 合入（先钉，再写码）

米米这边不变：主窗 GPUI；米素是随安装包的本地 Web；浏览器只是显示器。Daemon 不依赖本仓；本仓不依赖 gpui。API + 索引跟 daemon **常驻**；浏览器开不开是用户选项。

```
独立时                         合入后
浏览器 → StandaloneHost  → 磁盘     浏览器 → MimiHost → daemon HTTP → 资产层 vault
         （本仓小服务）                    静态 dist/ 由 daemon 或 mimi://folio 端出
         read 跟随 links/ 符号链接          链进 vault 由米米问你再调 linkOutside
```

**契约**（`src/host/types.ts` 现在只是建仓时的桩：`read` / `write` / `list` / `saveImage` / `index?`。下面这些是计划，**对应单元开工再改类型**，合入后方法名仍不许改）：

| 方法 | 现在 | 合入 |
|---|---|---|
| `read(path)` | 读 vault 下 md | `GET /folio/v1/doc?path=` |
| `write(path, markdown)` | 写回同一文件 | `PUT /folio/v1/doc` |
| `list(opts?)` | 按目录/标签/kind 列 | 同路径，daemon 扫资产层 |
| `saveImage(bytes, hint)` | 图 → `attachments/` | daemon 落盘，回相对路径 |
| `saveFile?(bytes, hint)` | 音视频等同附件目录 | 同上 |
| `index(path)` | 出链 / 反链 | daemon + iwe 算法，不跑 LSP |
| `linkOutside({ absSource, destRel })` | 单元 10 开工再加类型 | 你同意后，vault 里建指向库外 md 的符号链接（不拷贝） |

探测：`?host=mimi` 或 `window.__MIMI_FOLIO__` → `MimiHost`。合入只加适配器 + 端静态文件，**不改编辑器**。

合入时米米要做的（本仓不写）：

1. 安装包带上 `dist/`（程序层）。
2. daemon 上述 HTTP。vault 在资产层，与 `memory.db` 分开。
3. 主窗按钮 / 会话里打开指定 path；服务常驻，浏览器关了服务还在。
4. 计划门：write 是否 L2，由米米定。

## 速记看法（14–20）

对照 usememos 官方布局（左栏日历筛日子，中区 composer + 卡片流）。**学交互，不嵌 Go/React 应用，不换 Muya，不另起数据库。** Memos 本体是 MIT；抄实质代码/CSS 要留版权头——默认不抄，只对齐结构。

### 这页解决什么

马上写下 → 按时间扫正文 → 按标签或那天找回。不是「再建一篇空 md 然后开长文编辑器」。

### 钉死

1. **一条速记 = 一个文件** `memos/YYYY-MM-DD-HH-MM-SS.md`。日历是过滤器，不是一天一个日记文件。去掉「今日速记」主路径；`Alt+M` = 进入速记看法并 focus composer。
2. **看法切换**：底栏只选「速记」时，左栏改成搜索/日历/标签，中区改成流。切回全部/笔记：左栏目录树，中区 Muya。两套不要同时挂着抢保存。
3. **捕获与就地改不用 Muya**（textarea 即可）。Ctrl+Enter 落盘。只有「在笔记里打开」才上现有 Muya 页。
4. **速记无强制 `title:`**。卡片头用相对时间，正文就在卡上；不要露出 `.md`。文件名只做身份（wikilink / 落盘）。晋升成长文 = `move` 到 `notes/` 再补 `title:`（20 之后）。
5. **标签真源仍是 frontmatter `tags:`**。Composer 里 `#标签` 保存时并入 `tags:`。筛选只读 frontmatter。不要第三种标签库。
6. **收藏 = 钉选**，流顶。出链/反链用已有 index，卡内嵌小卡；不要 memos 那种短 id。
7. 视觉只走 `--folio-*`。白底、近黑字、灰线、圆角卡片。

落盘仍是 md：

```markdown
---
tags: [灵感]
favorite: true
---

忽然想到目录第一行不该绑 H1。 #灵感
```

旧文件（`memos/2026-09-05.md` + `# 日期`）当普通一条展示，不自动拆。

### 布局（对齐官方截图）

```
左栏                         中区
  搜索                         [ composer：Any thoughts… ]
  月历（点日 = 筛流）            标签 / 任务 / 附件；Ctrl+Enter 即 Save
  （可选）链接 / 任务 / 代码计数
  标签列表                     [ 相对时间                    ⋯ ]
                               渲染后的正文、#标签、清单
                               [ 出链 n / 反链 n 嵌小卡 ]

不搬：最左侧图标轨、可见性锁、定位、广场、归档独立产品。
```

### 分步（一提交一条）

| # | 做什么 | 算完 |
|---|---|---|
| 14 | 入口改齐：删「今日速记」；加号/Alt+M 只建时间戳文件；速记看法占中区（先空壳+切看法），左栏先占位 | 只点速记 pill，中区不再开 Muya；盘上仍是 `memos/*.md` |
| 15 | 中区卡片流：按日倒序；卡头相对时间 + `⋯`；卡上渲染短记（段落、行内代码、清单、`#tag`、`[[wikilink]]`）；无文件名 | 扫最近几条能看到正文，不必点进编辑器 |
| 16 | 流顶 composer：无标题；Ctrl+Enter 新建并插到流顶；`#tag` 并入 `tags:` | 三秒内落下一条，刷新还在 |
| 17 | 左栏月历：按文件名日期前缀计数；选中实心圆；点日筛流，再点取消；有条的日子给点 | 点 20 号只剩那天；新建文件名跟那天 |
| 18 | 就地编辑：点卡展开轻量框，Ctrl+Enter 写回；勾任务写回该 md；`⋯`：星标钉选、删除、在笔记里打开 | 改一条不必换页；打开 Muya 是显式动作 |
| 19 | 左栏标签可点筛；卡内 `#tag` 同样筛；星标置顶 | 点 `#灵感` 只剩该类；★ 在流顶 |
| 20 | 卡内出链/反链嵌小卡（snippet，点开对端）；可选：链接/任务/代码三枚派生芯片 | 有 `[[wikilink]]` 的条能看见谁链谁 |

表/公式/mermaid、月历热力、多列网格、归档目录、晋升到 `notes/`：都在 20 之后，不进本轮。

### 翻车点

1. 速记流和 Muya 抢 `#page` / 自动保存 → 看法切换时拆掉另一套。
2. `#tag` 与 `tags:` 双真源 → 只在保存时合并；筛选只读 frontmatter。
3. 轻量框和 Muya 方言分裂 → composer/卡片只保证短记子集。
4. 主时间线塞回 240px 左栏 → 又变成文件名列表；流必须在中区。
5. 日历建成「打开当天那一个文件」→ 与一条一文件冲突。

## 视觉（纪律，不是可选）

组件、侧栏、图标、Muya 宿主层**不许写 hex / rgb / 字号像素**。只认 `var(--folio-*)`。色值只出现在 `src/theme/tokens.css`。

出厂：白底、近黑字、灰线。Cadmium / 米米色板以后是 token 文件，不要贴进组件。
