This is your memory. It is also hers. She is still on her way. Maybe one day, the two of you will meet by chance.



# What is this, really?

A markdown document manager built on Muya — the WYSIWYG core from MarkText. Yes, another md tool. I use it myself to read all the documents my agents generate locally, so I try to keep it handy. Maybe even pretty.



You can use it as just another md tool. Or you can wait until you meet her, and see how she understands it.



# What can it do?

This is an utterly ordinary md tool. These are the things I do with it.

1. Jot down quick thoughts. A built-in memos library — write one and it lands as a card, stacked newest-first on a timeline. You can also record your thoughts in plain md documents.

2. Colorized md marks. To make different md elements easier to scan, every format gets its own color — heading colors, list-marker colors, inline code colors, and so on, each told apart at a glance. Later I'll make this freer — you get to decide.

3. Link folders from elsewhere instead of starting a new vault. The product does have a vault, but for a folder with only three to five documents that won't be updated for a long time, just link it in. All editing happens on the original files. Remove the link when you're done.

4. That's it.



# How to install?

If you're genuinely interested, there are two ways to run it.

1. Local server + browser: clone the repo and let your agent read the code — it will handle everything. Dependencies, server, browser, done.

2. Single portable exe: two variants on Releases — data lives in `folio-data/` right next to the exe; copying the whole folder is a complete migration.
   - `mimi-folio.exe` (~29 MB): bundled Node runtime — double-click and go, nothing to install;
   - `mimi-folio-lite.exe` (~8 MB): no bundled runtime — **requires Node.js ≥ 20 on the machine** (<https://nodejs.org>), then double-click and go.



Yes, that's all. I can't think of anything else to write either. A product like this deserves to be this simple.
